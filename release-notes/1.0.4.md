Conveniences for running the application and its API separately, plus a browser profile setting.

- With the APIs running **Separately**, the API's browser window (its Swagger page) belongs to the API: closing it stops the API, and **Stop API** closes it. With the **external** browser, or together with the project, it stays an independent tab that stops nothing.
- New **Run all** / **Stop all** buttons for the APIs running **Separately**: Run all starts the API, waits until it is ready and then runs the project (if the API fails, the project is not run); Stop all stops both.
- New **Open API** button: opens the running API's page (its Swagger if it uses one) again, for example when the window did not open by itself.
- New **Browser profile** setting for the project's browser window: **Temporary** (default, as before) or **Persistent** (a DotPilot profile kept between runs, so sessions, passwords and extensions stay once you sign in or install them there). Closing the window stops the app with both. Recent Chrome and Edge versions do not allow the debugging connection on your everyday profile, so a linked window cannot use it; to use your everyday browser choose the system default browser, which does not stop the app.
- Run API / Stop API now use the same play and stop icons as the application's.
- Internal: a Release workflow publishes a version when its tag is pushed.
