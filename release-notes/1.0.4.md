- With the APIs running Separately, the API's browser window (its Swagger page) now belongs to the API: closing it stops the API, just as closing the project's window stops the project, and Stop API closes it. With the external browser, or together with the project, it stays an independent tab that stops nothing. / Con las APIs en ejecución por separado, la ventana del navegador de la API (su página de Swagger) ahora es de la API: cerrarla detiene la API, igual que cerrar la ventana del proyecto detiene el proyecto, y Detener API la cierra. Con el navegador external, o juntas con el proyecto, sigue siendo una pestaña independiente que no detiene nada.
- New setting Browser profile (dotpilot.browserProfile) for the project's browser window: Temporary (default, as before) is a linked Edge or Chrome window with a clean profile that is deleted on close; Persistent is a linked window whose DotPilot profile is kept between runs (sign in once and your sessions, passwords and extensions stay). With both, closing the window stops the app. Recent Chrome and Edge versions do not allow the debugging connection on your everyday profile, so a linked window cannot use it; to use your everyday browser choose the system default browser, which does not stop the app. / Ajuste nuevo Perfil del navegador (dotpilot.browserProfile) para la ventana del navegador del proyecto: Temporal (predeterminado, como antes) es una ventana vinculada de Edge o Chrome con un perfil limpio que se borra al cerrar; Persistente es una ventana vinculada cuyo perfil de DotPilot se conserva entre ejecuciones (inicias sesión una vez y tus sesiones, contraseñas y extensiones permanecen). Con ambos, cerrar la ventana detiene la app. Las versiones recientes de Chrome y Edge no permiten la conexión de depuración en tu perfil de siempre, así que una ventana vinculada no puede usarlo; para usar tu navegador de siempre elige el navegador predeterminado del sistema, que no detiene la app.
- The second Run / Stop pair (Run API / Stop API) now uses the same play and stop icons as the application's in the editor toolbar and the status bar (where it is told apart by the word API), instead of circled icons. / El segundo par Ejecutar / Detener (Ejecutar API / Detener API) usa ahora los mismos íconos de play y stop que el de la aplicación en la barra del editor y en la barra inferior (donde se distingue por la palabra API), en lugar de íconos con círculo.
- Two new buttons for the APIs running Separately: Run all starts the API, waits until it is ready and then runs the project (if the API fails, the project is not run), and Stop all stops the API and the project. They are in the panel, the DotPilot menu and the command palette. / Dos botones nuevos para las APIs en ejecución por separado: Ejecutar todo inicia la API, espera a que esté lista y después ejecuta el proyecto (si la API falla, no se ejecuta el proyecto) y Detener todo detiene la API y el proyecto. Están en el panel, en el menú de DotPilot y en la paleta de comandos.
- New Open API button (panel, DotPilot menu and command palette): it opens the running API's page, its Swagger if it uses one, again; useful when the window did not open by itself or the system browser was used. / Botón nuevo Abrir API (panel, menú de DotPilot y paleta de comandos): vuelve a abrir la página de la API en marcha, su Swagger si lo usa; sirve cuando la ventana no se abrió sola o se usó el navegador del sistema.
- Internal: a Release workflow publishes a version when its vX.Y.Z tag is pushed (tests, VSIX, GitHub Release and, with a VSCE_PAT secret, the Marketplace); the steps are in CONTRIBUTING.md. / Interno: un flujo Release publica una versión al subir su etiqueta vX.Y.Z (pruebas, VSIX, Release de GitHub y, con el secreto VSCE_PAT, el Marketplace); los pasos están en CONTRIBUTING.md.
